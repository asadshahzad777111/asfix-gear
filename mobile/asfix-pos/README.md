# AsFix POS (Android)

Light **Capacitor 6** shell that opens the live POS (`https://asfixgear.com/pos`) and prints receipts over **classic Bluetooth SPP** (ESC/POS) — **no Thermer** on the happy path.

App id: `com.asfixgear.pos` · Name: **AsFix POS**

## AsFix POS vs vendor APK vs Thermer

| App | Install | Prints AsFix receipts? |
|-----|---------|------------------------|
| **AsFix POS** (this folder) | Build debug APK below | **Yes** — native SPP + website ESC/POS (32-col 58mm + `ESC Z` QR) |
| **Thermer** (`mate.bluetoothprint`) | Play Store | Yes from **Chrome** share/Intent only |
| **BT-POSPrinter.apk** (seller ZIP) | Sideload from vendor pack | **No** — hardware demo only; not wired to asfixgear.com |

Windows `PrinterDriver.exe` from the same ZIP is laptop-only; see [`docs/thermal-printer-windows.md`](../../docs/thermal-printer-windows.md). Do **not** commit APKs/EXEs into git (`_ci_local/` is gitignored).

## What this is / is not

| In scope | Out of scope |
|----------|----------------|
| Android phone + paired Bluetooth thermal printer | Windows laptop driver / OPOS / macOS |
| ESC/POS bytes via RFCOMM UUID `00001101-0000-1000-8000-00805F9B34FB` | Embedding vendor `BT-POSPrinter.apk` |
| Auto-print after sale when staff is in this app | Shipping a Play Store release (you build debug APK) |

**Honest limit:** Pair the printer in **Android Settings → Bluetooth** first. This app lists **bonded** devices and opens an SPP socket. BLE-only gadgets may need a different path (web BLE on laptop is separate). Website JS updates (receipt layout / QR) deploy with Vercel — reopen the app after push to `main`.

Community ESC/POS Capacitor plugins exist, but quality/maintenance varies; this repo uses a thin in-house plugin `AsfixThermalPrint` so we own the SPP send path.

## Prerequisites

1. Node 20+ (repo uses newer Node fine)
2. [Android Studio](https://developer.android.com/studio) with SDK 34 + a device/emulator
3. USB debugging enabled on the phone (for debug APK install)
4. Thermal printer powered on and **paired** in Android Bluetooth settings

## One-time setup

```bash
cd mobile/asfix-pos
npm install
cd plugins/asfix-thermal-print && npm install && npm run build && cd ../..
npx cap add android
npx cap sync android
npx cap open android
```

In Android Studio: wait for Gradle sync → Run on your phone (or **Build → Build APK(s)**).

### Local WebView against Vite (optional)

```bash
# LAN IP of your PC, Vite must listen on 0.0.0.0
set ASFIX_POS_SERVER_URL=http://192.168.x.x:5173/pos
npx cap sync android
```

Default `server.url` is production: `https://asfixgear.com/pos`.

**Note:** Frontend native auto-print hooks ship with the website. After changing `frontend/`, deploy (or point `ASFIX_POS_SERVER_URL` at local Vite) before testing print on device.

## Install debug APK on phone

1. Android Studio → **Build → Build Bundle(s) / APK(s) → Build APK(s)**
2. Locate `android/app/build/outputs/apk/debug/app-debug.apk`
3. Copy to phone and open, or: `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`
4. Open **AsFix POS** → staff login → Counter bill

## Pair printer + auto-print

1. Android Settings → Bluetooth → pair your ESC/POS printer (often named “BlueTooth Printer” / BT800S).
2. In AsFix POS Counter: **Select printer** → choose the bonded device (saved in Capacitor Preferences).
3. Confirm a sale → receipt **auto-prints once** (native only).
4. Manual **Print** also uses the same SPP path inside this app.
5. Expect **full 58mm width**, readable items, and **Scan + QR** at the bottom (`https://asfixgear.com`).

Desktop Chrome / phone browser still use existing bridge / Thermer / share behavior — unchanged. iPhone cannot BT-print; use Print chooser → this Android station.

## Permissions (Android 12+)

Manifest requests `BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN` (neverForLocation), plus legacy Bluetooth permissions for older APIs. The plugin calls `requestPermissions()` before list/connect/print. If Android shows a rationale dialog, allow Bluetooth.

## Plugin API (`AsfixThermalPrint`)

| Method | Purpose |
|--------|---------|
| `listPrinters()` | Bonded Bluetooth devices |
| `connect({ address })` | RFCOMM SPP connect |
| `printText({ text, address? })` | ESC `@` + text + feed + cut |
| `printEscPos({ dataBase64, address? })` | Raw bytes |
| `getStatus()` / `disconnect()` / `requestPermissions()` | Lifecycle |

Native source: `plugins/asfix-thermal-print/android/.../AsfixThermalPrintPlugin.kt`
